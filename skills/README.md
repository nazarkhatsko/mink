AI agent skills for generating mink flows.

## Available

| Skill | Description |
|---|---|
| [generate-flow](claude/generate-flow/SKILL.md) | Generate a mink flow YAML from a description |

## Install

```bash
# Claude Code
bash skills/claude/generate-flow/install.sh
```

After install, use `/generate-flow` as a slash command in your AI agent.
